## Conventions

- Everything in this repository is written in English: code, comments, README, docs, commit messages and issues.

## Agent skills

### Issue tracker

GitHub issues on the public repo `linagora/dcs-onlyoffice` (`gh` CLI). Issues are public: nothing internal or sensitive. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
